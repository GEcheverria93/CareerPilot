Frontend: React + Vite + TypeScript + Tailwind CSS + TanStack Query + Zustand.
Backend: Node.js + Express + TypeScript.
Base de datos: PostgreSQL (Supabase en desarrollo).
ORM: Prisma.
Automatización: Playwright.
Cola de tareas: BullMQ + Redis.
Autenticación: JWT + Refresh Tokens.
Validación: Zod.
Logs: Pino.
Testing: Vitest (frontend) y Jest o Vitest (backend).
Monorepo: Turborepo (si el proyecto crece).
Gestor de paquetes: pnpm. 
Las decisiones técnicas registradas en este documento son consideradas estables. Ninguna IA debe reemplazar una tecnología por otra (por ejemplo Express por NestJS, Zustand por Redux, Prisma por Drizzle, etc.) sin una solicitud explícita del desarrollador y una justificación técnica documentada.
