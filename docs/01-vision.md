# CareerPilot

## Visión

CareerPilot es una plataforma piloto diseñada para reducir al mínimo el tiempo que una persona invierte buscando oportunidades laborales.

El objetivo principal no es enviar currículums masivamente, sino analizar el CV del usuario, encontrar ofertas compatibles y facilitar la postulación de forma automática o asistida.

CareerPilot automatiza las tareas repetitivas del proceso de búsqueda de empleo, como recorrer múltiples portales, localizar ofertas relevantes y centralizar la información en un único lugar.

La plataforma estará construida de forma incremental.

El MVP piloto tendrá un único objetivo:

> Ayudar al usuario a encontrar ofertas compatibles con su CV y a postularse con la menor intervención posible.

Las funcionalidades iniciales serán:

- Análisis del CV.
- Creación de un perfil profesional básico.
- Búsqueda de ofertas compatibles.
- Ranking por compatibilidad.
- Postulación asistida o automática en un alcance limitado.

Funciones futuras como métricas avanzadas, IA más profunda o automatización masiva podrán añadirse si el piloto demuestra valor y rentabilidad.

## Principios

- Resolver primero el problema principal.
- Automatizar únicamente tareas repetitivas.
- Mantener una arquitectura modular y escalable.
- Construir una base sólida antes de agregar funcionalidades avanzadas.
- Priorizar calidad y mantenibilidad por encima de la velocidad de desarrollo.
- Usar la IA como apoyo complementario, no como el eje central del MVP.
