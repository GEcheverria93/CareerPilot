# 07 - User Interface (UI)

# Objetivo

La interfaz de CareerPilot deberá ser simple, intuitiva y orientada a la acción.

El usuario nunca deberá preguntarse cuál es el siguiente paso.

Cada pantalla tendrá un único objetivo y evitará mostrar información innecesaria.

La aplicación priorizará rapidez, claridad y productividad por encima de efectos visuales o configuraciones avanzadas.

---

# Filosofía

CareerPilot no busca impresionar al usuario.

Busca ayudarlo a conseguir trabajo lo más rápido posible.

Cada interacción debe acercar al usuario a ese objetivo.

---

# Principios de Diseño

- Interfaz limpia.
- Pocas pantallas.
- Pocos clics.
- Sin menús complejos.
- Sin información duplicada.
- Todo orientado a la búsqueda laboral.

# Onboarding

La primera vez que un usuario utilice CareerPilot deberá completar un proceso guiado.

## Paso 1

Crear perfil.

Información mínima.

- Nombre
- Correo electrónico

---

## Paso 2

Subir CV.

Formatos soportados:

- PDF
- DOCX

---

## Paso 3

Análisis automático.

CareerPilot detectará automáticamente:

- Experiencia
- Tecnologías
- Certificaciones
- Idiomas
- Áreas de trabajo

---

## Paso 4

Confirmación.

El usuario podrá editar la información detectada antes de continuar.

La IA nunca modificará información sin confirmación del usuario.

---

## Paso 5

Preferencias laborales.

Configuración inicial:

- País
- Modalidad
- Categorías de empleo

Una vez completado el proceso se habilitará el Dashboard.

---

# Dashboard

El Dashboard será la pantalla principal de CareerPilot.

No tendrá gráficos durante el MVP.

Su objetivo será mostrar únicamente información útil para comenzar una búsqueda laboral.

Contenido principal:

- Botón "Buscar ahora"
- Cantidad de ofertas nuevas
- Lista de ofertas
- Estado de búsqueda

---

# Navegación

La navegación deberá mantenerse simple.

Se utilizarán únicamente cuatro secciones principales.

- Ofertas
- Favoritas
- Historial
- Perfil

No se implementarán menús complejos durante el MVP.

---

# Vista de Oferta

CareerPilot mostrará una vista propia antes de redirigir al usuario al portal original.

La información incluirá:

- Empresa
- Puesto
- Ubicación
- Modalidad
- Fecha de publicación
- Resumen de la oferta
- Requisitos principales
- Tecnologías solicitadas
- Botón "Abrir oferta"

El usuario decidirá cuándo abandonar CareerPilot para continuar la postulación en el portal correspondiente.

---

# Fuera del alcance del MVP

No forman parte de la primera versión:

- Dashboard analítico.
- Gráficos.
- Matching visual.
- Estadísticas.
- Comparativas.
- Temas personalizables.
- Configuración avanzada.

Estas funcionalidades podrán incorporarse en futuras versiones sin modificar la experiencia principal.
