# Job

Representa una oferta laboral obtenida desde cualquier fuente.

Nunca conoce el portal original.

# Connector

Responsable de obtener ofertas desde una fuente externa.

Nunca contiene lógica de negocio.

# User

Persona que utiliza CareerPilot.

# Resume

CV del usuario.

Puede tener múltiples versiones.

# Profile

Información profesional derivada del CV y editada por el usuario.

# Search

Proceso de obtención de ofertas.

# Ranking

Proceso que decide el orden de las ofertas.

# Provider

Fuente externa de información.

Ejemplo:

LinkedIn

Computrabajo

ZonaJobs
